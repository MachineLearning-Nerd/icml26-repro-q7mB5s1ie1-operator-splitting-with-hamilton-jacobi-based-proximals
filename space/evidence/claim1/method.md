# Method

`reproduction.verify_claim1` is independent of the certificate data. It
requires the exact source quantifier, all seven inference records, all `n`
coordinate contributions in the integration-by-parts identity, and the
nonsmooth limiting step. It exits nonzero on any missing or mutated obligation.

The negative control changes the summed coordinate count from `n` to `n-1`.
The same checker must reject it for that specific reason.
