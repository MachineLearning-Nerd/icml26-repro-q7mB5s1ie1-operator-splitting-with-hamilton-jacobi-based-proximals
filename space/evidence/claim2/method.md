# Method

The checker derives function properties from independent built-in definitions,
checks the PGD step bound and all summability exponents, and validates an
explicit `N_k` witness satisfying both Assumption 3.4 sample conditions. It
then checks the descent and divergent-drift certificates.

The negative control replaces the globally Lipschitz linear `g` with a
quadratic while claiming the same theorem. It must be rejected specifically
because global Lipschitzness fails.
